# QN Website Pro 2.0
موقع QN لتجارة المواد الغذائية — RTL / responsive / GitHub Pages ready.

## المزايا
- كتالوج منتجات قابل للتوسعة
- فلاتر للمنتجات
- طلب المنتج مباشرة عبر WhatsApp
- طلب عرض سعر
- قسم عروض
- العربية / English
- Dark / Light
- PWA manifest
- مشاركة الموقع وحفظ جهة الاتصال
- هوية QN الأخضر والذهبي

## GitHub Pages
ارفع محتويات المجلد إلى جذر المستودع بحيث يكون index.html بجانب مجلد assets.
ثم Settings → Pages → Deploy from a branch → main → /(root).
